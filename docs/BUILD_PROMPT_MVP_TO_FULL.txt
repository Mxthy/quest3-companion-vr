## 2. Harte Produktregeln
- Adult-Build explizit gewünscht – Touch, Zonen, Arousal, virtuelles P, Wirkung sichtbar.
- Agency-Niveau: Captain-Hardcore-Typ Steuerung (Spieler agiert, Körper reagiert) – eigene Systeme, kein CH-IP/Code/Assets.
- Keine Meshes/Audio/Code aus Referenz-APKs im Produktbaum.
- Soft-Props (Cup, Vinyl, Laterne) bleiben; Adult-Pfad ist zusätzlich.
- VRM Vivi: Adult-Nutzung ok; nicht als eigenes Original-IP verkaufen (Meta/Author beachten).
- 18+-Warnung einmal pro Session.
- Keine Minderjährigen-Inhalte.
- Browser-FPS nicht als native Quest-Performance ausgeben.

## 4. Zielbild nach diesem Lauf
1. MVP-Loop (Enter, Props, Bond, Pause, Save) unvermindert
2. VRM-Companion sehen (Vivi oder Platzhalter)
3. Körperzonen per Hand/Controller → Arousal, Zeilen, Expression
4. Virtuelles P aus Headset-Pose (Höhe ~1.65m-Referenz, Yaw)
5. Adult-Props greifbar (auch Geo-Stubs)
6. Orgasmus-Peak lesbar
7. Optional: Enter VR, Teleport/Snap, gleiche Core-Logik

---

## 5. Implementierungsreihenfolge

### Phase 1 – Core ins MVP hängen
- Companion-Store/Phase nicht zerschießen.
- AdultInteractionController + IntimateContactSystem instanziieren.
- YAML laden oder DEFAULTS + Dialog-Konstanten.
- Pro Frame (playing): Handpunkte → tick.

### Phase 2 – VRM + Zonen
- VRM laden, Bones → Zonen.
- Events → Dialog aus adult_interaction.yaml + ExpressionWeights.

### Phase 3 – Virtuelles P
- HMD/Camera → computeVirtualAnatomy → Mesh.
- IntimateContact.tick mit zones + props.
- Prefer local-floor.

### Phase 4 – Props
- Soft wie MVP; Adult aus props_adult.yaml.
- Platzhalter-Meshes ok, IDs/Sockets müssen stimmen.

### Phase 5 – WebXR
- immersive-vr, Grip/Trigger, Teleport/Snap.
- Wissensspeicher webxr/* bei Unklarheit.

### Phase 6 – Feinschliff
- 18+-Gate, Mute, Save; Kurzreport Limits.

## 6. Frame-Loop (Soll)
if phase !== playing: skip oder nur Decay
hmd = XR viewer OR camera
anatomy = computeVirtualAnatomy(hmd)
apply shaft mesh transform
zones = VRM bones
propsSockets = adult props
hands = controllers OR desktop
out = IntimateContact.tick(...)
events → dialogue + audio + blendshapes
soft props parallel
